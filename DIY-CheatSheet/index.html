Attributes in HTML

Attributes are used in elements to give them extra information

Attribute Purpose Example
id Unique identifier <element id="attribute">
class Group identifier <element class="attribute">
<element class="attribute">
style Allows inline CSS styling <style>
 selector {
  color: white;
 }
</style>
type Allows selection of varying input types <input type="text">Input Text</input>
src Links to an external location <img src="folder/file.png">
